🧾 What is a List?
List is:
	A collection of items:	List items are indexed, the first item has index [0], the second item has index [1] etc.
	Ordered:		it means that the items have a defined order, and that order will not change.(There are some list methods that will change 				the order, but in general: the order of the items will not change.)
	Changeable (mutable):	meaning that we can change, add, and remove items in a list after it has been created.
	Allows duplicates:	Since lists are indexed, lists can have items with the same value:
				Example
					Lists allow duplicate values:
						thislist = ["apple", "banana", "cherry", "apple", "cherry"]
						print(thislist)

Why Use Lists?
	Jab aapko multiple values store karni ho ek variable mein.
	Jab aapko loop karke values access, modify, ya process karni ho.
	Jab aap file ya database se bulk data le rahe ho.

Python has a set of built-in methods that you can use on lists.

Method		Description
append()	Adds an element at the end of the list
clear()		Removes all the elements from the list
copy()		Returns a copy of the list
count()		Returns the number of elements with the specified value
extend()	Adds the elements of a list (or any iterable) to the end of the current list
index()		Returns the index of the first element with the specified value
insert()	Adds an element at the specified position
pop()		Removes the element at the specified position
remove()	Removes the item with the specified value
reverse()	Reverses the order of the list
sort()		Sorts the list

Lists are used to store multiple items in a single variable.
Lists are one of 4 built-in data types in Python used to store collections of data, the other 3 are Tuple, Set, and Dictionary, all with different qualities and usage.
Lists are created using square brackets:
	thislist = ["apple", "banana", "cherry"]
	print(thislist)

📘 List Syntax
	
	my_list = [10, 20, 30, 40]
	List can store:

	Numbers → [1, 2, 3]
	Strings → ["apple", "banana"]
	Mixed types → [1, "hello", 3.5]

🛠️ Common List Operations:
Operation		Code Example				Output
Create list		fruits = ["apple", "banana"]		['apple', 'banana']
Access item		fruits[0]				'apple'
Change item		fruits[1] = "mango"			['apple', 'mango']
Append item		fruits.append("kiwi")			['apple', 'banana', 'kiwi']
Remove item		fruits.remove("banana")			['apple']
Length of list		len(fruits)				2
Loop through list	for x in fruits: print(x)		apple\nbanana
Slice	fruits[1:3]						items from index 1 to 2
