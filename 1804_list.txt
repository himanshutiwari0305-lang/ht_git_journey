Q: x[0] means "list empty na ho"?
A: Nahi. x[0] ka matlab hota hai: list ka pehla element.
Agar list khali ho ([]) to x[0] se error aayega (IndexError).
List empty check karne ke liye: if x ya if len(x) > 0 use karo.

Q: print(x[0]) vs x[0] ka kya difference hai?
A:

x[0] value ko memory mein access karta hai

print(x[0]) us value ko screen pe dikhata hai
Agar aap x[0] likhte ho bina print ke, to kuch output nahi aayega.

Q: isdigit() error kyun aaya?
A:
Jab value already int hoti hai (30), tab uspe .isdigit() nahi chalega
Kyunki .isdigit() sirf string pe chalta hai.

cleaned = [
    x for x in employees[1:]
    if len(x) == 2 and x[0] and (
        isinstance(x[1], int) or (isinstance(x[1], str) and x[1].isdigit())
    )
]
🔹 Step 2: Age ko int mein convert karna
python

cleaned = [[x[0], int(x[1])] for x in cleaned]
🔹 Step 3: Average age nikalna

total_age = sum(x[1] for x in cleaned)
count = len(cleaned)
average_age = total_age / count
print("Average Age:", average_age)
