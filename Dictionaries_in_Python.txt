What is a Dictionary?
Python dictionary ek key-value pair based structure hota hai.

List/Tuple → positional (index se access)
Dictionary → labelled data (key se access)

Syntax:

employee = {
    "name": "Himanshu",
    "age": 42,
    "city": "Noida"
}
🔑 "name" = key
📦 "Himanshu" = value

🛠 Common Operations
✅ 1. Accessing values:
print(employee["name"])   # Himanshu

✅ 2. Add a new key-value:
employee["department"] = "HR"

✅ 3. Change value:
employee["age"] = 43

✅ 4. Delete a key:
del employee["city"]

✅ 5. Looping through dictionary:
for key, value in employee.items():
    print(key, ":", value)

✅ Add new employee:
employees.append({"name": "Sita", "age": 28, "city": "Pune"})

📌 Dictionary vs List vs Tuple

Feature		List		Tuple		Dictionary
Changeable	✅ Yes		❌ No		✅ Yes
Access		By index	By index	🔑 By key (more readable)
Use case	Ordered data	Fixed set	Structured records

Duplicates Not Allowed
Dictionaries cannot have two items with the same key:
employee = {
    "name": "Himanshu",
    "name": "Rekha",
    "age": 42,
    "city": "Noida"
}
print(employee["name"])-- this display Rekha and himanshu will not return

Dictionary Items - Data Types
The values in dictionary items can be of any data type:

Example
String, int, boolean, and list data types:

thisdict = {
  "brand": "Ford",
  "electric": False,
  "year": 1964,
  "colors": ["red", "white", "blue"]
}

The dict() Constructor
It is also possible to use the dict() constructor to make a dictionary.

Example
Using the dict() method to make a dictionary:

thisdict = dict(name = "John", age = 36, country = "Norway")
print(thisdict)

✅ Q3: employee.get("name") vs employee["name"] — Difference?
🎯 Both are used to get values by key — but there's one key difference:

Method	Description
employee["name"]	Direct access → gives error if key missing ❌
employee.get("name")	Safe access → returns None if key missing ✅
🔍 Example:
	employee = {"name": "Rekha"}

print(employee["name"])        # ✅ Rekha
print(employee.get("name"))    # ✅ Rekha

print(employee["city"])        # ❌ KeyError: 'city'
print(employee.get("city"))    # ✅ None (no error)
✅ So Use .get() when:
	1)You're not sure if the key exists
	2)You want to avoid errors

Dictionary Methods

Method		Description
clear()		Removes all the elements from the dictionary
copy()		Returns a copy of the dictionary
fromkeys()	Returns a dictionary with the specified keys and value
get()		Returns the value of the specified key
items()		Returns a list containing a tuple for each key value pair
keys()		Returns a list containing the dictionary's keys
pop()		Removes the element with the specified key
popitem()	Removes the last inserted key-value pair
setdefault()	Returns the value of the specified key. If the key does not exist: insert the key, with the specified value
update()	Updates the dictionary with the specified key-value pairs
values()	Returns a list of all the values in the dictionary


🔹 1. .keys() and .values()
	print(employee.keys())    # dict_keys(['name', 'age', 'city'])
	print(employee.values())  # dict_values(['Himanshu', 42, 'Noida'])
✅ Helpful when you just want keys or values only (like column names or all values)

🔹 2. .get() with default fallback
	print(employee.get("salary", "Not specified"))
	📌 If "salary" key doesn’t exist, it will return "Not specified" instead of error.

🔹 3. Nested Dictionary Example (Real World)
	employee = {
    	"name": "Himanshu",
    	"details": {
        	"age": 42,
        	"city": "Noida"
    	}
	}

	print(employee["details"]["city"])  # Access nested value
	✅ Used when you want to group info under categories.

🔹 4. List of Dictionaries (Most Used!)
	employees = [
    	{"name": "Neha", "age": 30},
    	{"name": "Amit", "age": 35}
	]

for emp in employees:
    print(emp["name"], emp["age"])
✅ Ideal for reading from files, APIs, databases, etc.
